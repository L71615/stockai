## 🎯 主线场景:T+1/T+2 短线预测

**用户场景**:
- 昨晚 22:00 收盘 → 自动跑 Pipeline 算因子 / AI 选股 / 多 Agent 辩论
- 用户 23:00 看 `/pipeline` 收件箱 → 审批通过 Top-5 推荐
- 次日 09:30 开盘 → 按推荐买入
- 第三日 → 卖出(规避 T+1 持仓成本)
- 月底 → AI 月报复盘

**v4.0 重点优化**:
- 隔夜跳空风险(开盘价 vs 昨收)
- 流动性约束(成交额/换手率过滤,避免流动性陷阱)
- T+1 持仓成本计入(卖出费用 + 持仓风险溢价)
- 次日开盘预期收益(综合考虑跳空/流动性)
