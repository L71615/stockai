# StockAI v4.0 — 第四次大更新计划

> **当前版本: v3.11**(2026-07-25)
> **下一大版本: v4.0**(规划中,2026-07-26 起)
> **定位**: StockAI 第四次大更新,三个战略方向并行

---

## 🎯 战略方向(D1 敲定 ✅)

用户已选定 v4.0 三个战略方向同时推进:

| # | 方向 | 含义 |
|---|------|------|
| **A** | 🧠 **AI 深度能力** | 多 Agent 架构强化、推理机制增强、RLHF 个性化交互、专属插件 |
| **B** | 📊 **因子与回测体系** | Alpha158 完整移植、回测引擎升级、多市场多周期支持 |
| **C** | 🔁 **决策与执行闭环** | 复杂组合管理、动态仓位/风控、证据链深化(基于 v3.11 拓展) |

### ⚠️ 核心红线(继承自 v3.11 + 加固)

- **预测 + 回测**,**不做实时量化**
  - 典型场景:T+1/T+2 短线预测 OR 周月大方向预测
  - **明确不做**:盘中 tick 级自动交易、券商对接、低延迟设计
- **白盒可解释**:因子表达式 / 特征重要性可见,不迷信黑盒

## 🗂 具体目标(待 D2-D4 敲定后填充)

### 🧠 A. AI 深度能力

- [ ] **多 Agent 强化**: 当前 5 角色辩论 → 升级到 8+ 角色,引入"做空研究员/政策解读员"
- [ ] **推理增强**: 让 AI 调用工具(`get_quote` / `get_factor` / `backtest`),不只纯对话
- [ ] **个性化**: 学习用户交易历史 + 反馈,微调 prompt
- [ ] **专属插件**: 用户自定义 AI 分析策略(YAML/JSON 配置)

### 📊 B. 因子与回测体系

- [ ] **Alpha158 完整移植**: 55 因子 → 158 因子,分 3 批:
  - Batch 1: 价量类(Q-15)
  - Batch 2: 动量/波动类(Q-15)
  - Batch 3: 技术/资金流类(Q-15 + 跨周期)
- [ ] **回测引擎升级**:
  - 滑点模型(默认 0.1% × 金额)
  - 冲击成本(基于成交量比例)
  - 多策略组合回测
- [ ] **多市场多周期**: A 股(已) + 港股/美股 + 周/月/年多周期

### 🔁 C. 决策与执行闭环

- [ ] **复杂组合管理**: 多策略并行,信号合并/冲突解决
- [ ] **动态仓位/风控**: 基于波动率 / 相关性矩阵的动态调仓
- [ ] **证据链深化**: v3.11 OOS 快照 + 影子组合 → 加"反事实 + Counterfactual 报告"完整化
